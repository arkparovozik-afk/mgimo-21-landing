# МГИМО × Школа 21

Концептуальный лендинг на Vite, React и TypeScript.

```bash
npm install
npm run dev
npm run build
```

Настройки стоимости, ссылок и CTA — `src/data.ts`. Форма работает в демонстрационном режиме и не отправляет данные. Перед публикацией следует подтвердить статус и условия следующего набора, расписание, учебный план, документы, преподавателей и политику обработки данных; подключить настоящий обработчик формы и согласовать использование материалов.
